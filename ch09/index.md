# Ch09 Alkynes: Reagent → Reaction Index

> Core themes: **sp C–H acidity** (`pKa ≈ 25`, deprotonated by `NaNH2` → SN2 alkylation on 1° RX); **stereospecific reduction** (Lindlar = **syn** → *cis*-alkene; `Li/NH3` = **anti** → *trans*-alkene); **hydration tautomerization** (`HgSO4/H2SO4` = Markovnikov → methyl ketone; `BH3/H2O2` = anti-Markovnikov → aldehyde).

| Reagent | Reaction | Family (syn / anti / cation / elimination / substitution / cleavage) |
|---|---|---|
| `2 H2, Pd/C (or PtO2)` | [Complete catalytic hydrogenation of alkynes (`hydrogenation-complete`)](cards/hydrogenation-complete.md) | syn (complete reduction to alkane) |
| `2 KOH, ethanol (or 2 NaNH2, NH3)` | [Dehydrohalogenation of vicinal dihalides (`dehydrohalogenation`)](cards/dehydrohalogenation.md) | elimination (twofold E2 elimination) |
| `BH3, THF (or R2BH); H2O2, OH⁻` | [Hydroboration–oxidation of alkynes (`hydroboration-alkyne`)](cards/hydroboration-alkyne.md) | syn (concerted syn hydration → enol → carbonyl tautomerization) |
| `Cl2 or Br2 (1 or 2 equiv), CH2Cl2` | [Addition of Cl2 and Br2 to alkynes (`x2-addition-alkyne`)](cards/x2-addition-alkyne.md) | anti (three-membered ring opened by back-side attack) |
| `H2, Lindlar catalyst` | [Partial catalytic hydrogenation (Lindlar catalyst) (`lindlar-reduction`)](cards/lindlar-reduction.md) | syn (concerted syn reduction to cis-alkene) |
| `H2SO4, H2O, HgSO4` | [Mercuric sulfate-catalyzed hydration of alkynes (`hgso4-hydration`)](cards/hgso4-hydration.md) | anti (mercurinium-type hydration → enol → ketone tautomerization) |
| `HX (1 or 2 equiv), ether` | [Addition of HCl and HBr to alkynes (`hx-addition-alkyne`)](cards/hx-addition-alkyne.md) | cation (vinylic cation / Markovnikov addition) |
| `KMnO4, H3O⁺ (or 1. O3; 2. H2O)` | [Oxidative cleavage of alkynes (`alkyne-cleavage`)](cards/alkyne-cleavage.md) | cleavage (oxidative cleavage to carboxylic acids / CO2) |
| `Li (or Na), NH3(l)` | [Lithium in liquid ammonia reduction (Dissolving metal) (`dissolving-metal-reduction`)](cards/dissolving-metal-reduction.md) | anti (radical anion → trans-vinylic radical → trans-vinylic anion → trans-alkene) |
| `NaNH2, NH3` | [Conversion into acetylide anions (`acetylide-deprotonation`)](cards/acetylide-deprotonation.md) | acid-base (deprotonation of terminal alkyne) |
| `NaNH2, NH3; RCH2Br (1° alkyl halide)` | [Alkylation of acetylide anions (`acetylide-alkylation`)](cards/acetylide-alkylation.md) | substitution (SN2 by acetylide anion) |
